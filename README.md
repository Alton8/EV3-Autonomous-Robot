# Autonomous EV3 Robot 🤖

This project controls a LEGO EV3 robot to **autonomously navigate an obstacle course** using color sensors and motor control.  
The robot detects different colored tape on the floor and performs programmed maneuvers — such as turning, or stopping -- based on the color identified.
